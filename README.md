# 공인중개사 필기 CBT

React·TypeScript·Vite 기반의 비공식 학습 앱입니다. 실전 모의시험, 랜덤 풀이, 오답노트, 북마크, 통계, 로컬 문제 등록·검수와 JSON 기록 백업을 제공합니다. 학습 기준/연도 선택 메뉴는 없고, 시험 **교시**를 선택할 수 있습니다. 실전은 답안 선택 후, 랜덤은 즉시 채점 후 Space로 다음 문제로 갑니다. 마지막 문제의 Space는 제출하지 않습니다.

## 개발

Node 24.19.0 (`.node-version`, engines >=22.12), npm 11.9, Python 3.12로 확인했습니다. Python은 문항 원고 재생성/재현성 테스트에 사용하며 앱 실행에는 필요 없습니다.

```sh
cd /workspace/Licensed-Real-Estate-Agent-CBT
npm ci
npm run dev
```

```sh
npm test
npm run build
npx playwright install --with-deps chromium
npm run test:e2e
```

클라우드에는 `/usr/bin/chromium`이 있어 다음 명령으로 브라우저를 재설치하지 않고 검증했습니다.

```sh
PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH=/usr/bin/chromium npm run test:e2e
```

별도 서버·DB·API 키·유료 서비스가 필요하지 않습니다. 각 클라우드 작업은 격리된 환경이므로 현재 checkout을 사용하고 요청 없이 Git worktree를 만들지 않습니다. 의존성은 유지되지만 개발 서버 프로세스는 새 작업에서 다시 시작해야 합니다.

## 시험 규칙: 공식 원문 확인 대기

**아래 값은 현재 학습용 설정입니다. 이번 작업에서 공식 문서를 열어 최신성을 확인하지 못했으므로 공식 시험 재현 완료로 보증하지 않습니다.** 확인 상태는 문제은행의 접을 수 있는 출처 상세와 이 문서에 표시하며 학습 화면 상단에 상시 면책 배너를 두지 않았습니다.

| 교시 | 구성 | 문항 | 시간 |
| --- | --- | ---: | ---: |
| 1차 | 부동산학개론 40 + 민법 및 민사특별법 40 | 80 | 100분 |
| 2차 1교시 | 중개사법령 및 중개실무 40 + 부동산공법 40 | 80 | 100분 |
| 2차 2교시 | 공시법 24 + 세법 16, **합산 한 과목** | 40 | 50분 |

객관식 5지선다, 채점 과목당 40문항·100점(문항당 2.5점), 각 과목 40점 이상·전 과목 평균 60점 이상을 적용했습니다. 미응답은 오답이며 표시용 반올림 전 값으로 합격을 판정합니다. 1차는 두 과목, 2차는 두 교시를 합친 세 과목으로 판정합니다. 2차 단일 교시 결과만으로 합격을 표시하지 않습니다. 통계에서 같이 평가할 두 교시 기록을 직접 골라 종합 결과를 봅니다. 이는 연습 기록 조합이며 실제 시험 응시자격·1차 면제·동차 처리까지 구현한 행정 판정은 아닙니다.

확인하려던 공식 자료: [Q-Net 공인중개사 시험정보](https://www.q-net.or.kr/crf005.do?id=crf00503&jmCd=9630). 요청 결과는 `curl: (56) CONNECT tunnel failed, response 403`, HTTP `000`으로 본문을 받지 못했습니다. `src/qualification.ts`의 `rulesVerificationStatus`는 `pending`입니다. 과목 세부 범위·최신 법령·공식 문항의 재배포 조건 대조는 미완료입니다. 읽지 않은 법령·교재를 문항의 정답 근거로 인용하지 않았습니다.

## 실제 문제은행: 1,000개

| 과목/영역 | 등록·내부 검수 | 계산 조건 변형 | 기본 개념형 |
| --- | ---: | ---: | ---: |
| 부동산학개론 | 200 | 200 (8 family × 25) | 0 |
| 민법 및 민사특별법 | 200 | 160 (8 family × 20) | 40 |
| 중개사법령 및 중개실무 | 150 | 150 (6 family × 25) | 0 |
| 부동산공법 | 150 | 150 (6 family × 25) | 0 |
| 부동산공시법 | 150 | 150 (6 family × 25) | 0 |
| 부동산세법 | 150 | 150 (6 family × 25) | 0 |
| **합계** | **1,000** | **960 / 40 family** | **40** |

자체 제작 1,000 · 원문 기출 0 · 복원 0 · 검증 대기 0 · 목표 부족 0개입니다. ID와 정규화한 본문·정렬한 보기의 지문이 각각 1,000개로 유일합니다. 숫자 조건 변형은 의도적으로 family로 묶었습니다. 서로 다른 상황이 같은 계산식을 쓰는 family도 있으므로 **40 family를 40개의 독립 수학 공식으로, 1,000문항을 1,000개 독립 개념으로 해석하면 안 됩니다.** 의미상 반복 유형과 제한된 범위를 숨기지 않습니다.

기출 원문·회차·정답·재배포 조건을 확인하지 못해 민간 문제를 복제하지 않았습니다. 모든 출제 연도·회차는 null입니다. 자체 원고는 CC BY 4.0(표시: Licensed-Real-Estate-Agent-CBT contributors)이며 원본 코드 MIT와 구별합니다. 각 문항의 저장소 링크는 작성 위치이고 외부 정답 증빙은 아닙니다.

중개·공법·공시·세법과 민법 계산형은 제시된 가정 아래의 수리 연습입니다. 법정 세율·보수 한도·허용 용적률·법률효과를 검증한 기출이나 법령 종합 대비 은행이 아닙니다. **공식 출제범위 전반을 충족하지 않으며 개념·판례·현행 법령 문항 보강이 필요합니다.** 내부 문장 검토·독립 계산 테스트를 외부 전문가 검수·공식 대조 완료와 구별합니다. 검수 내역과 40 family 목록은 [문항 검토 기록](docs/question-review.md)에 있습니다.

원고 재생성은 `python3 scripts/generate-bank.py`입니다. 고정 ID·순서·조건으로 동일 JSON을 생성하는지 테스트합니다. 실전 추출은 가능한 한 family당 한 문제를 먼저 고르고 부족하면 다른 고유 ID로 보충합니다. 변형이 많은 현재 은행은 한 시험에 같은 family가 여러 번 나올 수 있습니다.

## 기록과 가져오기

저장 키 `real-estate-agent-cbt:v1`로 다른 자격증의 localStorage와 분리합니다. 절대 종료 시각, 선택 답안, 랜덤 세션, 오답, 북마크, 로컬 문항을 저장합니다. 응답은 최근 5,000개, 시험은 최근 30회입니다. 백업은 JSON **내보내기**이며 UI 기록 복원은 제공하지 않습니다. 손상 원본 자동 덮어쓰기를 막고 저장 제한은 경고합니다. 초기화는 확인 후 사용자 기록·로컬 등록분만 지우고 기본 은행을 보존합니다.

JSON/CSV 가져오기는 브라우저 로컬 등록이며 공용 GitHub 은행을 변경하지 않습니다. 가져온 문항은 검증 대기로 들어가고, 근거 기록과 확인 체크 후 로컬 승인해야 학습에 사용됩니다. 출처·이용권한은 등록자가 확인해야 합니다. iframe/시크릿·브라우저 저장 제한과 origin별 기록 분리도 유의하세요.

## 검증과 배포 상태

최종 로컬 검사 결과와 환경은 [검증 보고서](docs/validation.md)에 기록합니다. 실기기 Safari/Android가 아니라 Chromium PC와 Pixel 7 에뮬레이션입니다.

`.github/workflows/pages.yml`은 **main push → 단위·타입/빌드·PC/모바일 검증 → Pages 자동 배포**, PR은 검증만 실행하도록 구성했습니다. deploy는 `needs: validate`, main 제한과 Pages/ID-token 권한만 사용합니다. 같은 커밋의 수동 실행을 추가하지 않습니다.

**이번 배포는 사전 네트워크 확인에서 중단됐습니다.** 대상 저장소의 GitHub API 요청이 `curl: (56) CONNECT tunnel failed, response 403`, HTTP `000`으로 차단됐습니다. API 권한·Pages Source·현재 게시 여부를 확인하지 못했고, 첫 파이프라인을 시작하지 않았습니다. 사용자 지시에 따라 API 재조회, main push, workflow 실행/재실행, 대체 배포를 하지 않습니다. 구현은 자동 배포가 없는 기능 브랜치로 보존하며 정확한 원격 결과는 최종 보고에 구별합니다. 다른 프로젝트는 수정·재배포하지 않았습니다.

예상 기본 주소: `https://YunSangYeong.github.io/Licensed-Real-Estate-Agent-CBT/`. **배포 성공 또는 공개 화면 확인 증거가 아닙니다.** 사용자 마무리의 첫 최소 동작은 클라우드 환경의 네트워크 허용 도메인에 `api.github.com`을 추가하는 것입니다. 그 후에도 이번 에이전트는 명시적인 새 배포 요청 없이 재시도하지 않습니다. 공식 자료 조사에는 별도로 `www.q-net.or.kr` 접근이 필요합니다.
