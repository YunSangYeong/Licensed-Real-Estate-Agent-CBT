# 새 클라우드 프로젝트에서 사용할 요청

아래를 복사한 뒤 자격증과 대상 저장소를 채운다. 다른 조건은 필요할 때만 추가한다.

```text
YunSangYeong/electrician-cbt 저장소의
.agents/skills/cbt-site-standard/SKILL.md와 references 폴더를 읽고,
지금 완성된 CBT를 표준으로 아래 자격증 CBT를 만들고 배포까지 진행해줘.

- 대상 자격증: [자격증명]
- 작업할 GitHub 저장소: [사용자명/새저장소]
- 배포 예정: GitHub Pages (에이전트가 진행, 나는 최초 설정·필수 승인만 지원)
- 추가 요구: [있으면 기입]
- 문제은행 목표 수: 검수 완료 1,000문항(표준 기본값)

먼저 스킬 폴더를 이 저장소에 복사하고,
기존 AGENTS.md를 보존하면서 연결해줘.
표준에 고정한 기준 커밋의 코드를 참고해 UI와 학습 기능을 재사용해줘.
학습 기준 선택 메뉴는 없애고, 두 모드 모두 Space로 다음 문제에 이동하게 해줘.
상단에 비공식·검증 대기·잠정 규칙 상시 안내 배너를 넣지 말아줘.
모바일 왼쪽 메뉴는 작은 높이·가로 모드에서도 위아래 스크롤이 되게 해줘.
실제 휠·터치 입력으로 하단 백업/초기화까지 내렸다가 상단 대시보드로 돌아오는지 확인하고 회귀 검사를 남겨줘.
비공식 표시는 푸터에, 규칙·출처·검수 한계는 문제은행/출처 문서에 기록하고
저장 실패·기록 손상 같은 실제 오류 경고는 유지해줘.

대상 자격증의 공식 시험 규칙·과목·문항 수·시간·합격·과락을 확인해 적용하고,
기출·복원·자체 제작과 계산 조건 변형을 구분해 보고해줘.
전기기능사 문제를 다른 자격증 문제로 복사하지 말아줘.
1,000문항은 기본 JSON에 실제 등록한 검수 완료 문항으로 집계하고,
중복·검증 대기·개인 로컬 등록분은 제외해줘. 부족하면 실제 수와 부족 수를 보고하고
표준 충족으로 처리하지 말아줘. 한 회 시험의 문항 수는 공식 규칙에 맞춰 별도로 설정해줘.
코드 구현, 필요한 단위·PC/모바일 테스트와 빌드,
허용된 GitHub 반영과 배포까지 네가 진행해줘.
이전 전기기능사 방식대로 main 푸시 후 검증에 성공하면 Pages 자동 배포로 이어지게 해줘.
PR 만들기·병합·Actions 실행을 나에게 전부 맡기지 말아줘.
내 관리자 권한으로만 가능한 최초 Pages 설정이나 환경 승인이 필요할 때만
그때 눌러야 할 메뉴를 한 단계씩 알려줘.
배포 전 권한·네트워크 확인을 포함해 한 번이라도 막히면 두 번째는 시도하지 말고
막힌 단계와 실제 오류, 배포 여부를 나에게 알려줘. 그때는 내가 직접 마무리하겠다.
첫 실패 뒤 workflow 재실행·다른 경로의 배포·배포를 유발하는 추가 푸시는 하지 말아줘.
이미 배포 완료된 다른 프로젝트는 수정하거나 재배포하지 말아줘.
로컬 검사·원격 반영·CI·배포·공개 화면 확인을 구분해서 보고해줘.
```

## 프로젝트에 따라 추가할 내용

- 공식 자료 URL, 사용이 허용된 원문·정답·이미지 파일, 확인된 이용 조건.
- PC/모바일 이외의 대상 기기, 추가 언어, 특별한 배점/과락/문항 형식.
- 블로그 iframe 사용 여부, 사용자 정의 도메인, 특별한 저장·백업 요구.

공식 자료를 AI가 알아서 확보했다고 가정하지 않는다. 최종 배포 권한은 사용자에게 있으며 저장소 접근·푸시 허용과 배포 실행을 구별한다. 원본 저장소와 새 저장소에 대한 접근도 실제로 확인해야 한다.
