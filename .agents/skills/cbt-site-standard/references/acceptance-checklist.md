# CBT 표준 인수 체크리스트

상태는 통과 / 실패 / 미실행 / 차단 / 해당 없음으로 기록하고 증거를 붙인다. 원본의 테스트 수를 합격 최소 수로 강제하거나 실행하지 않은 결과를 채우지 않는다.

| 영역 | 실제 확인 항목 |
| --- | --- |
| 시험 규칙 | 공식 자료의 자격증명·과목·문항 수·시간·보기·배점·합격·과락과 앱 설정 대조 |
| 설정·잔재 | 전기기능사 제목·전기 과목·60문항·60분·60점·4지선다·기존 저장 키·URL의 무비판적 복사 없음 |
| 상단 배너 | PC·모바일의 대시보드·시험·랜덤·결과 등 모든 화면에서 비공식/검증 대기/잠정 규칙의 상시 안내 배너 없음. 다른 색·문구로 재생성하지 않음. 비공식 표시는 푸터/사이드바, 확인 상태·한계는 문제은행/출처 문서에 기록. 실제 저장 실패·손상 경고는 유지 |
| 메인 | 두 모드·실제 학습 요약·최근 기록, 학습 기준/버전 선택 메뉴 없음 |
| 시험 추출 | 전체/과목 수 정확, 검증 대기 제외, ID 중복 없음, 변형 유형 과다 출제 방지 |
| 시간 | 정확한 시작/종료 시각, 백그라운드·새로고침 후 잔여시간, 만료 재접속 제출 |
| 답안 | 번호 이동·이전/다음·수정·미응답 표시·즉시 저장, 만료 후 수정 금지 |
| 제출 | 확인창 취소/확인, 시간 초과·수동 제출 중복 방지, 미응답 처리 |
| 채점 | 합격 경계 양쪽, 과목별 정확한 분모, 과락 포함, 표시 반올림과 판정 구분 |
| 해설 | 시험 중 비공개, 제출 후 전체 보기·정답·해설·출처, 오답만 보기·재학습 |
| 랜덤 | 전체/과목, 한 순회 내 중복 없음, 즉시 채점 한 번만, 연속 정답·정답률 |
| Space 공통 | 두 모드에서 답안 선택→본문 포커스→Space 이동, 미응답과 길게 누르기 보호 |
| Space 경계 | 마지막 문제에서 자동 제출 안 함, 네이티브 답안/다음 버튼·입력·IME·메뉴·대화상자 유지 |
| 기록 | 새로고침 복원, 북마크·오답·취약 과목·최근 점수, 재학습 정답 시 오답 해제 |
| 저장 | 자격증별 namespace, 기존 ID/기록 보존, 손상/쿼터/차단 경고와 원본 보존 |
| 초기화·백업 | 확인 후 로컬 사용자 데이터 초기화·기본 문제 유지, JSON 백업의 실제 제공 범위 |
| 문제 수 | 기본 JSON에 중복 제거 후 검수 완료 1,000문항(사용자 명시 수량 우선), 과목·단원별 배분, 검증 대기·오류·중복·개인 로컬 등록분 제외, 실제 수·부족 수 보고 |
| 문제은행 | JSON/CSV 양식·등록·오류 행·원자적 검증·중복·검증 대기·승인 근거·검색·페이지·내보내기 |
| 출처 | 실제 기출/복원/자체 제작 수, 연도·회차 근거, 이용 권한 확인, 검증 대기 제외 |
| 계산 | 독립 재계산, 단위·식·대입·반올림 경계·정답 번호·동치 보기, 숫자 변형 내역 공개 |
| 개념·규정 | 개념·해설 문장 검수 범위와 전문가 검수·공식 기준 대조 상태를 구별 |
| 재현 | lockfile·런타임·원고·생성 시드·고정 ID, 생성 반복 시 동일 결과와 다른 자료 보존 |
| PC·모바일 | 큰 글씨·보기 간격·번호 패널·가로 넘침·포커스·모바일 메뉴, 에뮬레이션/실기기 구분 |
| 모바일 메뉴 스크롤 | 390×480 작은 높이·짧은 가로 화면·글자 확대에서 독립 세로 스크롤. 실제 입력으로 아래 이동→하단 백업/초기화 접근→위 이동→대시보드 접근. 터치는 휠과 별도 확인, 애니메이션 완료 후 검사, 배경만 움직이면 실패. 자동 회귀 검사와 에뮬레이션/실기기 범위 기록 ([절차](mobile-menu-scroll.md)) |
| 배포 진행 | 배포 요청·base·브랜치·권한·정확한 커밋·실제 실행 확인. 요청받은 새 프로젝트는 에이전트의 main push → 검증 → Pages 배포, PR은 검증만. 사용자는 최초 설정·필수 승인만 지원. 금지/수동 전용 지시 우선 |
| 첫 차단 시 중단 | 배포 전 권한/네트워크 거부·최초 파이프라인 실패·사용자 조치 필요를 기록하고 재실행/다른 경로/배포 유발 추가 푸시 없음. 정상 상태 조회와 재배포 구별 |
| 문서 작업·제외 프로젝트 | 문서/스킬 변경만으로 배포 실행 없음. 이미 배포 완료 또는 사용자 제외 저장소 수정·재배포 없음 |
| 공개 사이트 | 배포 성공 후 접근 가능한 공개 화면·주요 기능 확인. 차단/승인 대기/미실행을 성공과 구분하고 필요한 최소 사용자 동작만 안내. 사용자 마무리 후 읽기 검증 요청을 재배포 요청으로 해석하지 않음 |
| 블로그 | 기본 iframe URL 유지, iframe에 포커스를 둔 Space·스크롤·저장 접근 제한 확인 |

보고서에는 검사 명령·작업 디렉터리·종료 코드·테스트 수·기기/브라우저·정확한 커밋·실제 실행한 CI/배포 결과와 필요한 최소 사용자 조치를 적는다. 미배포는 실패로 세지 않으며 배포 성공을 창작하지 않는다. 문서와 스킬만 바뀌는 작업이면 앱 테스트를 불필요하게 재실행하거나 사이트 배포를 요구하지 말고 문서 구조와 참조를 검증한다.
