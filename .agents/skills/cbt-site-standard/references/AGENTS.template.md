# 자격증 CBT 개발 지침

이 프로젝트의 CBT 신규 제작·수정·검증 작업은 먼저
[CBT 사이트 표준](.agents/skills/cbt-site-standard/SKILL.md)과 필요한 references를 읽고 수행한다.
사용자 지시와 상위 지침을 우선하며 기존 프로젝트 규칙과 변경을 보존한다.

- 전기기능사 기준 앱의 최종 화면과 기능을 참고하되 대상 자격증의 시험 규칙·문항은 별도로 검증한다.
- 문제은행 기본 목표와 완료 기준은 검수 완료 1,000문항이다. 중복·검증 대기·개인 로컬 등록분은 제외하며 사용자 명시 수량이 있으면 우선한다. 미달이면 실제 수와 부족 수를 보고한다.
- 페이지 상단의 비공식·검증 대기·잠정 규칙 상시 배너는 만들지 않는다. 안내는 푸터·문제은행/출처 문서에 두고 실제 저장 실패·손상 경고는 유지한다.
- 모바일 고정 메뉴는 작은 화면·가로 모드에서도 전체 항목을 위·아래로 스크롤할 수 있어야 한다. 실제 휠·터치 입력과 상단 대시보드/하단 도구 접근을 확인하고 자동 회귀 검사를 남긴다.
- 학습 기준·연도 버전 선택 메뉴는 만들지 않는다. Space 다음 문제는 실전·랜덤 모두 지원한다.
- 대상 자격증명·과목·출제 수·시간·보기·배점·합격·과락, 문제 출처·이용 조건을 확인한다. 전기기능사 수치를 복사하지 않는다.
- 기존 데이터와 Git 이력을 덮어쓰지 않는다. 다른 자격증 자료나 기출 연도·출처를 창작하지 않는다.
- 사용자가 배포까지 요청하면 에이전트가 구현·검증·Git 반영과 배포 진행을 맡는다. 새 프로젝트는 기본적으로 main push → 검증 → Pages 자동 배포 흐름을 사용하고 사용자에게 PR 생성·병합·Actions 실행 전체를 넘기지 않는다. 사용자는 최초 설정·필수 승인만 지원한다. 배포 금지·수동 전용 지시는 우선하며 배포 요청이 없으면 실행하지 않는다.
- 배포 전 확인부터 첫 권한·네트워크 거부/실행 실패/사용자 조치 필요가 나오면 중단하고 알린다. 두 번째 배포 시도·workflow 재실행·대체 경로·배포를 유발하는 추가 푸시는 하지 않는다. 정상 실행의 읽기 상태 조회는 재배포가 아니다. 사용자가 다시 명시적으로 요청하기 전에는 재시도하지 않는다.
- 문서·스킬만 변경할 때는 자동 배포를 시작하지 않는다. 이미 배포된 별도 프로젝트나 사용자가 제외한 저장소도 수정·재배포하지 않는다. 자세한 절차는 스킬의 references/deployment-workflow.md를 따른다.
- 스킬 목록에 없더라도 파일을 읽어 적용한다. 파일 복사를 계정 공통 스킬 설치로 표현하지 않는다.

이 문서는 새 저장소의 루트 AGENTS.md에 적용하는 양식이다. 기존 파일이 있으면 통째로 교체하지 말고 위 참조와 필요한 규칙만 병합한다.
